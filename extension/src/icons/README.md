# Icons

Rendered from the Phosphor `browser` (regular weight) master in `source/` by `npm run icons`.

Do not hand-edit the PNGs. Change the master, or the sizes/colour in `scripts/render-icons.mjs`, and re-render.
Colour: Trust Blue `#0066FF` (Geeksblock brand token).

Icon source: Phosphor Icons (`@phosphor-icons/core`), MIT licence — one family, bundled locally, per
`~/.agents/brand/iconography-standard-v1-2026-08-17.md` and AGENTS.md.
